# Credits console — historical archive

The original Credits back office is now maintained inside the **[Credits Platform project](https://github.com/ShenghangWang/entroqi-credits-platform/tree/main/back-office)**. Continue all frontend and backend work there; do not create a second console or resume implementation in this repository.

The owner authorized consolidation and public console source on **4 November 2026 (Asia/Shanghai)**. The earlier repository split kept the Vue interface private while Credits was public; a separate source repository was not a technical or product requirement.

All five original commits through `64275f2b9f576c5a7df2ca87127e1d72ef09dc75` were imported into Credits without squashing. The initial imported tree exactly matches `eca3fdb4200967411d03313670c12f428ece8a25`; frontend implementation, lockfile and reuse provenance are preserved. [Consolidation PR](https://github.com/ShenghangWang/entroqi-credits-platform/pull/3) records the import and verification.

This public repository is retained as an archived provenance/recovery copy, not deleted. Original source/history remain available here and in Credits. The updated build, CI, container and operating instructions live in [Credits](https://github.com/ShenghangWang/entroqi-credits-platform) and its [console guide](https://github.com/ShenghangWang/entroqi-credits-platform/blob/main/back-office/README.md). Existing repository backup bundles and source hashes are preserved.

Public source does not expose staff credentials, operational databases or operator access, grant a software license, or activate a payment service. Simulation and Atlas source remain private.
